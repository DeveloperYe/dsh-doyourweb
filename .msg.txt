feat: merge upstream 0.1.7-0.1.9 (uploads, network capture, diagnostics, sidebar) as 0.5.0

Brings the three upstream releases our fork skipped into dsh-doyourweb-remote while
keeping every remote-browser capability this fork adds.

New in the engine: authorized local-file uploads (browser_upload, upload/drag/drop
steps, cross-origin iframe targets), content-free network capture
(browser_network_requests), stage-by-stage command diagnostics, a view-only
"handle" observe mode, and scope:"main" reads. connectOverCDP now sets isLocal so
Playwright stops converting upload paths into base64 payloads.

New in the client: the native browser sidebar, context blocks folded into
expandable reference chips (model payload unchanged), in-page activity hint with a
stop button, annotation toolbar that collapses and docks, and desktop reads that
present a window once per connection.

Deliberately NOT merged: the management-token leak that 0.1.7 introduced. /manage,
/setup and the extension zip still require the per-start secret, and the RPC
prefix stays dsh-doyourweb-remote.

Test-suite adaptations for this fork: 连接设置 is expanded by default so the popup
step forces it open instead of toggling; pairing goes through the badge PIN and
/setup/pair; the management page is loaded from manageUrl(); upload path assertions
normalise through realpath so 8.3 short TEMP paths no longer fail.

Verified: build, npm test 166/166, test:browser (5 PASS blocks incl. upload, drag,
drop, network redaction, HUD stop), test:generated, verify:host 13/13.
